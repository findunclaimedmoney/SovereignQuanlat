# Sovereign Quant Super Agent Dashboard

Offline-first multi-agent quantitative trading workstation.

## One-command launch

### Windows
Double-click `run.bat`  
or open a terminal in this folder and run:

```
run.bat
```

### Mac / Linux

```
chmod +x run.sh
./run.sh
```

Then open your browser to: **http://localhost:8501**
